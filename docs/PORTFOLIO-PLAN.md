# Portfolio Upgrade Plan — Himanshu Pal

## Positioning

**Business Analytics & Operations | Data-led decision support | Process automation**

The portfolio should communicate one coherent proposition: a business-minded BMS student who can analyse information, understand how operations work, automate repetitive workflows, and help teams make better decisions.

The strongest current evidence is in analytics/reporting, process automation, ERP/inventory workflows, and applied data work. Marketing, sales, consumer behaviour, and entrepreneurship should be presented as developing business foundations—not as senior specialist experience.

## Brand and visual direction

Use the requested three-colour identity:

- Cream canvas: `#F5DABF`
- Deep green structure: `#0F3D3A`
- Bordo emphasis: `#6C151E`

Design direction: warm editorial / modern business journal. Keep the portfolio's strong typography, section numbering, responsive grids, project cards, and restrained motion, but remove the dark-cinematic treatment. Use cream as the dominant page surface, green for text and structure, and bordo for emphasis and important actions. Chart previews should use only tints and transparency of these same colours.

## Project presentation format

Each project case study should eventually include:

- Business context or problem.
- Goal and scope.
- Your role and contribution.
- Process: source data → preparation → analysis / workflow → output.
- Screenshot or short recording of the actual work.
- Tools used.
- Result or learning. Use a numerical impact claim only when it can be verified.

Current dashboard artwork is a visual placeholder. It must be replaced with authentic, sanitized screenshots before the portfolio is treated as final.

## Evidence and asset checklist

| Project | Assets to provide | Details to confirm |
|---|---|---|
| Cars24 Power BI | Full dashboard screenshot; one or two report-page screenshots; optional Power Query Editor screenshot | Dataset row/column count, important measures, visuals used, insights you actually found |
| Excel automation | Dashboard screenshot; source-data view with sensitive values removed; short screen recording of the refresh/update flow | Excel features used, how refresh works, what updates automatically, reporting frequency and time saved (if measured) |
| Motor-insurance workflow | Sanitized workflow diagram or demo screenshots; no customer, policy, insurer-login, or employer-confidential data | Your exact contribution, workflow stages automated, approval checkpoints, how the turnaround comparison was measured |
| Inventory ERP | Inventory overview, stock movement ledger, transfer/issue flow screenshots | Which modules you implemented, transaction types, users/locations covered, tested outcomes |
| Meal service platform | Dashboard screenshot with demo data; subscription/delivery flow diagram | Whether this was a concept, prototype, or deployed workflow; metrics should be marked illustrative unless real |
| Touchless Cursor | Short demo video or GIF; one clear interface screenshot | Supported gestures, libraries, and known limitations |

## Accuracy rules

- Clearly distinguish delivered work, prototypes, and concepts.
- Keep employer and customer information confidential; redact identifiers and private data.
- Label sample dashboards and mock numbers as illustrative.
- Do not claim advanced marketing, sales, finance, or operations expertise where the evidence is still developing.
- Prefer specific process and analysis examples over long lists of tools.
- Confirm employment dates, title wording, awards, and certification names before public release.
